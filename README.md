## DEFINICIÓN DE LÍNEA BASE

**Definición:** Posterior a cada corrección (Parciales/Trabajos Prácticos).  
La línea base del repositorio se definirá luego de cada instancia de corrección formal (ya sea parcial o trabajo práctico) por parte del docente o equipo evaluador.

**Justificación:**  
Al establecer la línea base después de la corrección, se evita que versiones preliminares o con errores sean utilizadas como referencia para futuras actividades, permitiéndonos identificar con claridad qué versión fue aprobada y cuándo, lo que mejora el seguimiento del proyecto y la gestión de cambios.
